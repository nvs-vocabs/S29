# S29
BODC parameter semantic model physical entity names

Terms used to describe physical entities in the BODC Parameter Usage Vocabulary

Governance: British Oceanographic Data Centre

## Request for new terms and ways to contribute
- Requests for a new S29 can be submitted as [regular issues](https://github.com/nvs-vocabs/S29/issues) in this repository or emailed to vocab.services-at-bodc.ac.uk.

- Reporting errors or suggestions for improving content can be also be submitted as above.
